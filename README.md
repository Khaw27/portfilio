# 🌸 Miya.Portfolio ✨
> Personal Portfolio เว็บแอปพลิเคชันแบบสไลด์เดี่ยว (Slide-Style Presentation Web) สไตล์เรียบหรู ทันสมัย โทนสีพาสเทลละมุน (Pastel Color Palette)

สำหรับ **นางสาว รวงข้าว บุญยเลขา (มีญ่า)**  
สาขาเทคโนโลยีสารสนเทศและการสื่อสาร (ICT) | มหาวิทยาลัยศรีปทุม (SPU)

---

## 🎨 จุดเด่นด้านการออกแบบ (Design & Aesthetics)
- **Pastel Color System:** คุมโทนสีพาสเทลอ่อนหวาน ละมุนตา
  - Soft Lavender (`#B892FF`)
  - Pastel Pink (`#FFC6FF`)
  - Mint Green (`#CAFFBF`)
  - Warm Butter & Cream (`#FFF9FB`, `#F8F5FF`)
- **Glassmorphism:** แถบ Header และการ์ดเนื้อหาแบบกระจกฝ้าโปร่งแสง ขอบมนละมุน (16px–28px) พร้อมเงาฟุ้งกระจาย (Soft Diffused Shadows)
- **Responsive Web Design:** รองรับทั้งหน้าจอเดสก์ท็อป แท็บเล็ต และสมาร์ตโฟนได้อย่างสมบูรณ์แบบ
- **Interactive Micro-Animations:** แอนิเมชันลอยตัวละมุน (Ambient Glow Orbs, Floating Sparkles), การ์ดยกตัวเมื่อ Hover และเสียงเอฟเฟกต์แบบ Soft Pop/Chime ผ่าน Web Audio API

## 🕹️ การควบคุมและการใช้งาน (Interactive Controls)
- **การเลื่อนสไลด์ (Smooth Slide-Snap):** ใช้ล้อเมาส์ (Scroll Wheel) เลื่อนขึ้น-ลง สไลด์จะ Snap เข้าตำแหน่งพอดี
- **ปุ่มนำทางลอยด้านข้าง (Side Dots & Arrows):** คลิกจุดหรือลูกศรขึ้น/ลง เพื่อเปลี่ยนสไลด์
- **คีย์ลัดบนแป้นพิมพ์ (Keyboard Navigation):**
  - <kbd>↓</kbd> / <kbd>→</kbd> / <kbd>Space</kbd> / <kbd>PageDown</kbd> : ไปยังสไลด์ถัดไป
  - <kbd>↑</kbd> / <kbd>←</kbd> / <kbd>PageUp</kbd> : กลับไปยังสไลด์ก่อนหน้า
  - <kbd>Home</kbd> / <kbd>End</kbd> : ไปยังสไลด์แรก / สไลด์สุดท้าย
- **ปุ่มเปิด/ปิดเสียงเอฟเฟกต์:** ปุ่มรูปลำโพงด้านบนขวา
- **ปุ่มโหมดนำเสนอเต็มหน้าจอ:** ปุ่มขยายหน้าจอด้านบนขวา (Fullscreen Presentation)
