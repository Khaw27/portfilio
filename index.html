COURSE 01

OOP & Data Structures

การเขียนโปรแกรมเชิงวัตถุและโครงสร้างข้อมูล

เข้าใจหลักการ Encapsulation, Inheritance, Polymorphism และการจัดการหน่วยความจำอย่างมีประสิทธิภาพผ่าน Stack, Queue, Linked List และ Tree Algorithms

Logical Thinking Clean Code
COURSE 02

Modern Web App Development

การพัฒนาเว็บแอปพลิเคชันสมัยใหม่

HTML5 & CSS3 Modern JavaScript RESTful API Responsive UI/UX
SPA Architecture Frontend & Web
COURSE 03

Database Systems & DB/SQL

ระบบจัดการฐานข้อมูลและการออกแบบ SQL

การวิเคราะห์และออกแบบฐานข้อมูลเชิงสัมพันธ์ (Relational Database) การทำ Normalization, ER-Diagram และการเขียนคำสั่ง SQL เพื่อจัดการข้อมูลอย่างถูกต้องและปลอดภัย

Relational DB SQL Queries ER-Diagram Data Normalization
CRUD Operations Data Integrity

Computer Networks & Security

เครือข่ายคอมพิวเตอร์และความมั่นคงสารสนเทศ

สถาปัตยกรรมเครือข่าย TCP/IP, OSI Model, Subnetting, Routing & Switching และการรักษาความปลอดภัยของข้อมูลดิจิทัลเพื่อป้องกันภัยคุกคามทางไซเบอร์

TCP/IP & OSI Routing & Switching Cybersecurity Network Protocols
Infrastructure Cyber Defense
